Theme Manager preview

Seasonal artwork, permanent palettes and personal themes for Jellyfin Web. Each user chooses their own theme; server branding, Custom CSS and library images are not changed.

Status

Where users see themes

Always available: . TV and mobile apps with their own interface do not show personal themes.

TV and mobile apps

Apps with their own interface (Android TV, Swiftfin, Roku and others) cannot show a personal theme. Theme Manager can instead set each library's image from the server default theme, changing with the calendar. The original images are backed up first and put back when you switch this off.

Switch off other tools that change library images first, for example a scheduled script, or they will overwrite each other.

Theme gallery

My theme preference

Saved to your signed-in Jellyfin account, not this browser. Users choose their own with the Themes button in Jellyfin Web.

Server default

Holidays in Automatic Seasonal

Unticked holidays are skipped; the month's theme shows instead. Users can still choose them as a fixed theme.

Calendars

Your own "Automatic Seasonal": choose which theme shows on which dates. Shared calendars can be chosen as the server default and by every user.

Theme packs

ZIP containing theme.json and PNG/JPEG/WebP artwork. No scripts or external URLs. Existing packs are never overwritten. Import parent packs before their variants.
